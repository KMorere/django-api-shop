# Introduction
This project is a web application made with Django and DRF (Django Rest Framework), simulating an online shop selling articles.  
Each article references a produce that will be sold, and separated by a category (Such as "Fruits").  
A guest will be able to view the content whereas an administrator will manage the content to display.  

# Purpose
The purpose of the application is to give users access to the shop's content with an API.

-----

# Installation
The project uses version 3.12 of Python and version 3.2.5 of Django,  
You can download the packages via the requirements.txt file with the following command :  
> pip install requirements.txt

## Instructions
Once all packages are download, the local server is launched using command :
> python manage.py runserver
